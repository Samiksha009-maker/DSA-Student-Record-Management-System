# DSA Mini Project Report

## Project Title
Student Record Management System

## Aim
To create a simple program for managing student records and demonstrate data structures and algorithms.

## Objectives
- Add, view, search, update, and delete student records.
- Search for students using PRN/ID.
- Sort student marks in descending order.

## Technology Used
Python 3; built-in lists and dictionaries; no external packages.

## Methodology
Student records are stored in a list. Linear search checks each record for a matching PRN/ID. Bubble sort compares adjacent records and places higher marks first. A menu allows the user to choose each operation.

## Algorithms Used
- Linear Search — O(n) worst-case time.
- Bubble Sort — O(n²) worst-case time.

## Result
The program provides a menu-driven way to manage student records and demonstrates basic DSA concepts.

## Future Scope
Save records to a file or database, add input validation for names, and create a graphical interface.
